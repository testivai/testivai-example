# TestivAI Example

The smallest useful example of [TestivAI](https://github.com/mcbuddy/testivai-oss) —
open-source, local-first visual regression testing — guarding a static page.

> 👀 **[See the live report →](https://www.budisugianto.com/testivai-example/)** — regenerated by CI on every push. No install, no signup.

## What's here

- [`site/`](./site) — a small storefront page (with a deliberately dynamic clock)
- [`tests/visual.spec.ts`](./tests/visual.spec.ts) — three `snapshot()` calls
- [`.testivai/config.json`](./.testivai/config.json) — `ignoreSelectors: ["#clock"]` keeps the dynamic clock out of the diff
- [`.testivai/baselines/`](./.testivai/baselines) — committed reference screenshots + DOM
- [`.github/workflows/visual.yml`](./.github/workflows/visual.yml) — PR diff comments + `/testivai approve`
- [`.github/workflows/deploy-report.yml`](./.github/workflows/deploy-report.yml) — publishes the report to Pages

## Run it

```bash
npm ci
npx playwright install chromium
npm test          # capture + compare + write visual-report/index.html
npm run approve   # promote current captures to baselines (then commit)
```

Change something in `site/index.html`, run `npm test` again, and open
`visual-report/index.html` — you'll get a verdict (style-only / layout shift /
render noise), selector-attributed regions, and a heatmap diff.

On a PR, CI posts the diff as a comment; approve with:

```
/testivai approve --all
```

MIT · no account · nothing leaves your machine.
